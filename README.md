# Mohamed Diomande

I learn a field by building something real in it. I start with the people doing the work, find where time or quality is lost, build a first version and keep improving it where it's used. Most of what's here came out of that, across software, CAD, sensors and model training.

[Portfolio](https://granddiomande.com) · [LinkedIn](https://linkedin.com/in/diomandee)

## Public projects

| Project | What it is |
